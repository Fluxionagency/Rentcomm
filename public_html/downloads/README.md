# downloads/

Marketing assets served to registered realtors (and the report PDF once ready).
Files here are uploaded/replaced through the Admin Portal's Asset Manager:

- `fadayee-brochure.pdf`
- `social-media-pack.zip`
- `site-walkthrough.mp4`
- `unit-price-list.pdf`

This directory must be writable by PHP on the server (`chmod 755` is usually
enough on cPanel; use `775` if PHP runs as a different user than FTP).
